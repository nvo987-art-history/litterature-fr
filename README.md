# Littérature française

Site culturel et documentaire consacré à la littérature française.

**Site :** https://litterature-fr.nvo987.eu/  
**Organisation :** NVO987 – Culture Visuelle Moderne et Contemporaine  
**Site principal :** https://www.nvo987.fr/  
**Contact :** contact@nvo987.eu

## Présentation

**Littérature française** est un projet documentaire consacré aux écrivains et aux acteurs de la littérature française.

Le site présente les informations sous forme de catégories et de fiches, avec des liens vers les ressources publiques disponibles en ligne.

## Données

Les données sont principalement issues de **Wikidata**.

Les données provenant de Wikidata sont publiées sous la licence **CC0 1.0 Universal**, conformément aux conditions applicables à leur source.

Les informations peuvent être incomplètes, obsolètes ou contenir des erreurs. En cas de divergence, les sources officielles des institutions, organisations ou personnes concernées doivent être privilégiées.

## Catégories

Le site peut notamment présenter les catégories suivantes :

- Écrivains
- Poètes
- Romanciers
- Dramaturges
- Essayistes
- Critiques
- Traducteurs
- Éditeurs
- Autres acteurs de la littérature française

La liste des catégories peut évoluer avec les données disponibles.

## Fonctionnement

Le site est une interface web statique.

Les informations affichées sont chargées depuis le fichier `literature.json`.

Structure générale attendue :

    {
      "literature": [
        {
          "name": "Nom",
          "categories": [
            "Catégorie"
          ],
          "wikidata": "https://www.wikidata.org/",
          "wikipedia": "https://fr.wikipedia.org/",
          "website": "https://example.org/"
        }
      ]
    }

## Mise à jour

Les données sont destinées à être mises à jour régulièrement, avec un objectif de mise à jour hebdomadaire.

La fréquence réelle de mise à jour dépend des données disponibles dans les sources utilisées.
