# Littérature française — NVO987

Site documentaire consacré à la littérature française et aux personnes
associées à son histoire.

**Site :** https://litterature-fr.nvo987.eu/

## Présentation

Littérature française est une publication culturelle et documentaire en ligne
éditée dans le cadre de NVO987 – Culture Visuelle Moderne et Contemporaine.

Le site propose un index de personnes associées à la littérature française,
notamment :

- Auteurs
- Poètes
- Romanciers
- Dramaturges
- Essayistes
- Nouvellistes
- Traducteurs

Une même personne peut apparaître dans plusieurs catégories.

Lorsque les informations sont disponibles, les fiches peuvent contenir :

- un identifiant Wikidata ;
- une page Wikipédia en français ;
- un site web officiel.

## Données

Les données sont principalement issues de Wikidata.

Source :

https://www.wikidata.org/

Les données Wikidata sont disponibles sous la licence CC0 1.0 Universal.

Les données peuvent être incomplètes, modifiées ou corrigées à tout moment.
